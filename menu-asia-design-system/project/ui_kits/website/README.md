# UI kit — website

Marketing site for the restaurant, assembled from the same primitives as the digital menu.

- `Home.jsx` — `Hero` (brick ground, gold leaves, cut-out pho bowl), `Highlights` (three cards), `Popular` (`DishEntry` list on marble), `Footer` (ink slab with hours).
- `Contact.jsx` — address block plus a reservation form.
- `index.html` — click-through: Domů → Menu → Kontakt, with a confirmation `Toast`.

Copy is Czech, plain and factual; prices always carry "kč". Menu data is shared with the menu kit (`../menu/data.js`).
