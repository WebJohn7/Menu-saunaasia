Use `Button` for any action in a Menu Asia interface — ordering, filtering, submitting.

```jsx
<Button variant="primary" size="lg" onClick={order}>Objednat</Button>
```

Variants: `primary` (yellow fill / ink text — the only fill used on dark brick pages), `dark` (ink fill, for light marble pages), `danger` (chilli red), `outline` and `ghost` (inherit `currentColor`, so they work on both grounds). Sizes `sm | md | lg`; `full` stretches. Label copy is Czech, uppercase, one or two words.
